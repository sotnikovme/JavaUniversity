# Лабораторная работа 5

Графическое приложение на Swing/Java2D строит четыре графика зависимости времени операции от числа элементов: среднее и общее время добавления, среднее и общее время второй операции. Для новых измерений вторая операция — удаление; для логов из `laba3` — замена (`set`), поскольку лабораторная работа 3 не измеряла удаление.

## Запуск

Из каталога `laba5`:

```powershell
& 'C:\Program Files\JetBrains\IntelliJ IDEA Community Edition 2025.2.2\jbr\bin\javac.exe' -encoding UTF-8 -d out src\*.java
& 'C:\Program Files\JetBrains\IntelliJ IDEA Community Edition 2025.2.2\jbr\bin\java.exe' -cp out Main
```

Можно также запустить класс `Main` из IntelliJ IDEA.

**Открыть логи…** сразу открывает папку `C:\\main\\MIET\\sem3\\JavaUniversity\\logs` и позволяет выбрать несколько файлов. Поддерживаются также логи лабораторной работы 3 с показателями `setAverageTimeNs` и `setTotalTimeNs`. Режим **Совместный просмотр** показывает обе коллекции на одной координатной плоскости; в раздельном режиме каждый файл открывается на своей вкладке. Точки по размерам одной коллекции соединяются линией. При наведении на точку видны файл, число элементов и точное время.

Кнопки масштаба, флажки легенды и логарифмических осей управляют отображением. **Сохранить настройки** создаёт рядом с каждым загруженным логом файл `*.log.chart.properties`. При повторной загрузке настройки первого выбранного файла применяются автоматически. Чтобы переносить настройки, переносите лог вместе с этим файлом.

## Почему код устроен просто

В программе используются обычные классы, поля, массивы, `ArrayList`, `LinkedList`, циклы `for`, условные операторы, чтение и запись файлов и обработка исключений. Обработчики кнопок собраны в одном методе `actionPerformed`. Данные в логе ищутся по началу строки; настройки записываются как четыре строки `ключ=значение`. Точки рисуются методами `drawLine` и `fillOval`. Для логарифмических осей нужны методы `Math.log10` и `Math.pow`.
