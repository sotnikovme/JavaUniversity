# Лабораторная работа 4

Из каталога `laba4` в PowerShell: `javac -encoding UTF-8 -d out (Get-ChildItem src -Recurse -Filter *.java | Select-Object -ExpandProperty FullName)`, затем `java -cp out Main`. Также можно запускать из корня репозитория: `java -cp laba4/out Main`. Программа ищет настройки и данные в текущем каталоге или в его дочернем каталоге `laba4`.

Учётная запись из `settings.properties` (по умолчанию `root` / `root`) создаётся или обновляется при каждом запуске. Затем программа запрашивает логин и пароль. Последний логин предлагается как значение по умолчанию; пароль всегда вводится повторно. Значения `debug` и `autotests` принимают `true` или `false`.

Данные хранятся в UTF-8: `data/current_user.txt` (последний вошедший), `data/users.txt` и `data/vehicles.txt`. Строки разделены символом табуляции; ID уникален. Изменения через меню сохраняются сразу, пункты сохранения и загрузки позволяют вызвать операции вручную. Класс `CRUD` отвечает за создание, чтение, изменение и удаление пользователей и машин, а `DbHelper` — за загрузку и сохранение файлов. В демонстрационных данных есть оператор `operator` / `secret`. Лог дописывается в `logs/app.log` с метками времени. Пароли хранятся открытым текстом в рамках учебного задания.
